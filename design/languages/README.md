# Design languages

A design language is how one kind of product looks and behaves.

| Language | For |
|---|---|
| [`internal.md`](./internal.md) | An internal system — an admin, a back office, a tool staff keep open all day. Calm, dense, keyboard first; Linear as the reference for behaviour. |
| `public.md` | *Planned.* A public site, a landing page, a storefront. |
