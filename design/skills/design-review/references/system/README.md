# Design system

The middle layer between [foundations](../foundations/README.md) and
[patterns](../patterns/README.md): first the three-tier tokens, then the
components built strictly from them.

| Path | What it holds |
|---|---|
| [`tokens.md`](./tokens.md) | **Three-tier token architecture** — OpenDesign contract tokens, semantic app extensions, and component-scoped tokens. |
| [`tokens.json`](./tokens.json) | **Starter tokens as data** (W3C Design Tokens format) — light and dark OKLCH values, extensions, and component token defaults for `internal` and `public` density. |
| [`components/`](./components/README.md) | **Component specifications** — anatomy, variants, all six control states, tokens and accessibility for every core kit component. |
