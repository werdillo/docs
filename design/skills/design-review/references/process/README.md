# Process

How a product document becomes screens, states and copy — the bridge between
[`bizdev/product-document/`](../../bizdev/product-document/README.md) and
[`software/principles/web/ui/`](../../software/principles/web/ui/README.md).

A screen is never invented from a blank canvas. Every screen, control, edge
state and label traces back to a box, a process, a rule or a word in the
product document.

| File | What it holds |

| [`states.md`](./states.md) | **Every screen has all its states** — the nine states designed up front, with timing thresholds and transitions. |
| [`copy.md`](./copy.md) | **Words on screens** — microcopy rules: business words verbatim, verb-and-object actions, three-part errors, number and date formatting. |
