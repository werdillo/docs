# Design languages

A design language is how one kind of product looks and behaves. Both languages
share [the foundations](../foundations/README.md) and [the OpenDesign token
contract](../system/tokens.md), and differ in density, typography scale,
navigation chrome and interaction speed.

| Language | For |
|---|---|
| [`internal.md`](./internal.md) | **An internal system** — an admin, a back office, a tool staff keep open all day. Calm, dense, keyboard first; Linear for UX and behaviour, Apple macOS / HIG for colour palette and materials. |
| [`public.md`](./public.md) | **A public site** — a landing page, a storefront, a publication. Welcoming, mobile-first, scannable, fast to read and act on. |
