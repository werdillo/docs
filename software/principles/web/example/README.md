# Example: a small shop

The principles on one small project, from the folder tree to the code. The
shop starts with boxes only and gains each process when its signal shows —
the order a real project meets them in. The names are made up; the shapes are
the ones the rules ask for, and each step links to the rule it applies.

## Steps

| Steps | File | What it shows |
|---|---|---|
| 1–3 | [`day-one.md`](./day-one.md) | Boxes, `shared`, doors and declarations. |
| 4–6 | [`processes.md`](./processes.md) | Checkout, a process that reads, and a queued message. |
| 7–9 | [`growing.md`](./growing.md) | A plug, a link that stays, another domain reacting, and the whole shop. |
| — | [`tests.md`](./tests.md) | The tests, red and green. |
