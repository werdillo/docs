## Stage 1 — Idea

### 1. The idea

Клиенты записываются по телефону, администратор ведёт тетрадь, бывают накладки.

> For **небольших салонов красоты**, who **записывают клиентов по телефону и путаются**, **Запись** is **онлайн-запись** that **позволяет записаться самому**. Unlike **тетради и телефона**, it **не допускает двух записей на одно время**.

### 2. The problem

| | |
|---|---|
| **Who has it** | Салоны на 2–6 мастеров. |
| **How they solve it today** | Телефон, тетрадь. |
| **What it costs them** | Около 2 накладок в неделю, клиент уходит недовольным. |
| **Why now** | Администратор уходит в декрет. |
| **Evidence** | Тетрадь салона за 2 месяца; разговоры с 2 другими салонами. |

### 6. Scenarios

#### S1. Записаться к мастеру

- **Who:** Клиент
- **Starts when:** клиент открывает страницу салона.
- **Steps:** 1. Выбирает услугу. 2. Выбирает мастера. 3. Выбирает время. 4. Оставляет телефон.
- **Ends with:** запись создана.

#### S2. Посмотреть свои записи

- **Who:** Мастер
- **Starts when:** утром.
- **Steps:** 1. Открывает список записей на день.
- **Ends with:** мастер знает, кто придёт.
