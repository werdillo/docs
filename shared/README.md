# Shared

The common ground of every section — what product, design, software and
hardware have in common, below them, as a `shared` sits below the boxes of a
matrix. It holds one idea: **feature matrix design** — a thing's place says
what it is, to the business and to the developer alike.

The same matrix is drawn once, from the business, and then read by every stage:
a product document names the domains and boxes, design draws their screens,
and the code keeps them as folders, under the same names.

| File | What it holds |
|---|---|
| [`words.md`](./words.md) | The core words, defined once for every section. |
| [`matrix.md`](./matrix.md) | The idea: boxes, a matrix, the levels around it, and how boxes interact. |
| [`mapping.md`](./mapping.md) | What each word is in each section — product, design, web, low-level. |

**This is the source.** Business development, software and design all reason
in the feature matrix, so it is defined here and nowhere else. A section
applies it to its own field and adds the words only it has; it does not
redefine a core word. Where a section and this page disagree, this page wins
and the section is fixed; a change to the idea is made here first.

These pages were distilled from the two principle sets, which keep their own
fuller text for their field:
[web](../software/principles/web/structure/README.md) and
[low-level](../software/principles/low-level/structure/boxes.md).
